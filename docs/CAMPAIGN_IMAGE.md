# Ivory Muse campaign

`public/images/campaign/ivory-muse.webp` is an AI-generated editorial concept
created for the homepage, not a photograph of an inventory item. It does not
replace any catalogue product photography or link to a specific product.

The homepage uses a responsive photograph with subtle pointer-driven perspective.
This effect is disabled for reduced-motion preferences. The existing procedural
3D atelier remains available through the optional homepage button on WebGL2 devices.
